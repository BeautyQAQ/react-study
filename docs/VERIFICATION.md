# React 社区迁移验收

验证日期：2026-10-29。运行环境为 Node.js 22.23.1、Playwright 1.64.0、Chromium 148.0.7778.96。

| 检查 | 结果 |
| --- | --- |
| TypeScript strict 与 Vite 生产构建 | 通过 |
| Vitest 单元测试 | 38 / 38 通过 |
| 桌面端真实接口浏览器用例，1440 × 900 | 14 / 14 通过 |
| 手机端真实接口浏览器用例，390 × 844 | 14 / 14 通过 |
| 开发代理注册、回车登录、私有草稿自动保存与手机布局 | 通过 |
| Docker 生产资源、反向代理、健康检查与认证边界 | 通过 |
| 生产依赖 `npm audit --omit=dev` | 0 个漏洞 |

浏览器回归按桌面/手机、社区/后台联动分成四批完成，未跳过用例，未启用失败自动重试。覆盖范围包括：

- 注册登录与原页面返回、刷新恢复登录、邮箱验证和找回密码、主动修改密码与旧会话失效。
- 资料、头像归属与公开主页隐私，设置页归属检查。
- Markdown、图片上传与清理、发帖审核、修改后重新审核、作者查看审核状态、搜索。
- 评论及回复实际接收者、点赞收藏、关注与粉丝、通知与已读、私信及账号隔离。
- 精华与关注动态的公开状态过滤；并发草稿和同名标签提交。
- 草稿立即刷新恢复、账号隔离、草稿箱续写/发布/删除、断网同步、冲突保留与复制新主题。
- 井字棋胜负、平局、历史分支、重新开始、深色偏好以及手机页面无横向溢出。
- 现有管理后台审核、账号禁用/恢复、审计，以及只读权限、实时撤权和密码重置的服务端校验。

单元测试另行覆盖“草稿保存已提交但响应丢失”的重试、保存期间继续输入、重复发布防护，以及旧会话的迟到 401 响应不能清除新账号登录状态。

浏览器测试使用独立生成的 Compose 项目，实际运行两个后端、React 社区前端、现有管理前端、MySQL、Redis 与本地 SMTP。邮件通过实际 SMTP 投递到测试收件箱，测试不向外部邮箱发信。测试结束后移除本次环境的容器、网络、卷、应用镜像与生成的环境凭据。

复现方式见 [真实接口回归说明](../e2e/README.md)。测试截图和报告位于被 Git 忽略的 `e2e/.artifacts/`；该目录的诊断内容仅供本机使用。
